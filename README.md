# Pharmacy Info Hub

แหล่งข้อมูลจริงสำหรับวิเคราะห์กลยุทธ์ร้านยาชุมชนไทย ใช้ได้กับทุกรายวิชาและทุกพื้นที่

## ปรับให้แต่ละคลาสผ่านลิงก์

- `?course=` ใส่ชื่อวิชาหรือคลาส จะแสดงบนแถบด้านบนและท้ายหน้า
- `?area=` ใส่ชื่อจังหวัด ชื่อย่อ หรือรหัส HDC จะตั้งจังหวัดเริ่มต้นให้หน้า "ร้านยาในพื้นที่" และตัวสร้างลิงก์ HDC

ตัวอย่าง: `https://wirunw.github.io/pharmacyinfo/?course=PHA%20473%20ม.รังสิต&area=ปทุมธานี`
ถ้าไม่ใส่ จะแสดงแบบกลาง และเริ่มจากข้อมูลทั้งประเทศ

- **คลังข้อมูล**: แหล่งข้อมูลสาธารณะ 36 แหล่ง กรองตามหมวดและบทที่เรียน พร้อมสถานะการตรวจสอบ
- **ร้านยาในพื้นที่**: แดชบอร์ดใบอนุญาตขายยาจากชุดข้อมูลเปิดของ อย. (`data/licensees.json`) GitHub Actions ดึงจาก API ทุกวันจันทร์ (`scripts/fetch_fda.py`, `.github/workflows/update-fda.yml`) สั่งดึงเองได้ที่แท็บ Actions → Run workflow
- **เครื่องมือ**: ตัวสร้างลิงก์ HDC รายจังหวัด, Google Trends คลิกเดียว, เครื่องคิดเลขทำเล, ตาราง Telepharmacy 15 โปรแกรม, เทียบโปรแกรมร้านยา
- **แบบฝึก**: 5 แบบฝึกในห้อง 7–10 นาที เชื่อมกับแหล่งข้อมูล

ข้อมูลรวบรวม ณ พฤศจิกายน 2569 แก้รายการได้ที่ `assets/data.js` เว็บนี้เป็นไฟล์ static ไม่เก็บข้อมูลผู้ใช้ (เครื่องคิดเลขบันทึกในเบราว์เซอร์ของผู้ใช้เท่านั้น)
